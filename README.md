TCP клиент/сервер на языке Golang

Сервер слушает порт 8080 и при подключении отправляет сообщение "OK\n"
Клиент отправляет запрос на данный порт, получает сообщение с сервера и проверяет его на корректность и если все работает правильно отправляет сообщение о том что все успешно прошло и закрывает подключение.

Для одновременной обработки нескольких клиентов сервер использует горутины. Добавлены таймауты на подключение (DialTimeout), чтение (SetReadDeadline) и запись (SetWriteDeadline), чтобы сетевые операции не блокировались на неопределённое время. Также добавлена обработка ошибок, возникающих при создании, использовании и закрытии сетевых соединений.

Тесты корректно отрабатывают.

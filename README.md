TCP клиент/сервер на языке Golang

Сервер слушает порт 8080 и при подключении отправляет сообщение "ОК\n"
Клиент отправляет запрос на данный порт, получает сообщение с сервера и проверяет его на корректность и если все работает правильно отправляет сообщение о том что все успешно прошло и закрывает подключение.

Тесты корректно отрабатывают.
